# Wave Bikes — prévia conceitual

Prévia responsiva de presença digital para discussão com a Wave Bikes de Itapema. **Não é site oficial da loja.**

O protótipo demonstra três direções visuais e uma jornada de descoberta por categorias, pesquisa, favoritos, comparação e contato pelo WhatsApp. O botão de WhatsApp abre a conversa com texto preenchido; não envia automaticamente.

Os exemplos Watts BW3, Watts W1 e Shineray PT3 são referências públicas externas, consultadas em 27/10/2026. Não confirmam venda, representação ou estoque da Wave. A lista real de produtos, disponibilidade, preços, garantia, entrega e assistência precisa ser validada com Guilherme antes de uma publicação comercial.

`arte/apresentacao.png` é uma prancha montada com capturas do protótipo no navegador. Ela é material interno de revisão e não aparece como chamada na mensagem comercial.
